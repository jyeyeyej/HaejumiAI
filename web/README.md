# 해주미 PC 웹 첫 버전

Windows PC의 브라우저에서 사용하는 React 화면입니다. 기존 Node.js 참조 백엔드와 같은 `/api/v1`을 사용하며, 서버가 프로젝트·작업·버전·승인의 단일 데이터 원천입니다. 브라우저가 직접 고른 사진·영상 최대 20개를 한 프로젝트에 업로드합니다. 선택 상한은 빌드 환경변수 `VITE_MAX_SELECTED_MEDIA`로 1~30개 사이에서 변경하며 서버 상한과 맞춰야 합니다.

## 실행

1. 프로젝트 루트 `.env`에 기존 서버 인증값을 설정하고 `npm start`로 백엔드를 127.0.0.1:8765에서 실행합니다.
2. `cd web` 후 `npm ci`, `npm run dev`를 실행하고 `http://127.0.0.1:5173`에 접속합니다.
3. 서버 Bearer 토큰을 화면에 직접 입력합니다. 토큰은 탭 메모리에만 보관하므로 새로고침하면 재입력이 필요합니다.
4. 결과물 빌드는 `npm run build`, 로컬 빌드 미리보기는 `npm run preview` (`http://127.0.0.1:4173`)입니다.

Vite 개발·미리보기 서버는 모두 127.0.0.1에만 바인딩되며 `/api/v1`만 127.0.0.1:8765로 프록시합니다. 백엔드도 loopback에만 바인딩됩니다. 외부 공개용 서비스 구성이 아닙니다.

## 현재 범위

- 예투 홈의 규칙 기반 대화, Creator 사용 가능 카드와 Schedule·Wellness·Diary 준비 중 카드.
- 수동 파일 선택·해시 검증·업로드·프로젝트 생성, 소유 프로젝트 목록.
- 서버에서 다시 읽은 기획·자막 초안·체크포인트, 버전 기반 수정·중간 승인, 렌더 요청·상태·취소, 인증된 실제 FFmpeg MP4 해시 확인 후 재생.
- HTTP 409 충돌 시 서버의 최신 작업을 다시 조회. 주기적 조회와 탭 복귀 시 조회로 다른 기기의 변경을 반영.

PC 첫 버전에는 플랫폼별 게시 정보·최종 게시 승인 화면, PC 음악 등록·권리 증빙 화면, 구조화 장면 편집, 음성/STT가 없습니다. Android에는 플랫폼별 게시 정보·독립 최종 승인 화면 코드가 있지만 실기기에서 검증되지 않았습니다. 실제 SNS 게시는 양쪽 모두 없습니다. 외부 AI 동의·호출 기능은 웹에 없으며 서버 기본값은 비활성입니다.

## 테스트

`npm test`는 API 요청 구성·선택 업로드 manifest·안전 오류 메시지 단위 테스트입니다. `npm run build`는 React 산출물 빌드입니다. Android 실기기와 두 기기 간 실제 동시 동작은 별도 검증이 필요합니다.
