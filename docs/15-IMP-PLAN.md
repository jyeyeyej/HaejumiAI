## 실행 전략
**Creator Agent 중심으로 수직 슬라이스를 먼저 완성**하고 능동형 Android와 SNS, 전체 예투로 확장합니다. 기간은 PC 성능·API 심사에 따라 변동되므로 고정 일정보다 완료 조건으로 관리합니다.

| 단계 | 범위 | 산출물/완료 조건 |
|---|---|---|
| 0. 환경 | Git, Docker, Python, FFmpeg, DB, 기본 보안 | README대로 로컬 기동 |
| 1. 로컬 편집 PoC | 사진/영상 업로드, FFmpeg 컷 편집 | 30초 9:16 파일 1건 생성 |
| 2. 자막·음악 | STT/자막 에디터, 라이선스 확보 음악 | 자막·음악 삽입 영상 재현 |
| 3. Creator MVP | LangGraph 계획, Worker, 권리 게이트, React 미리보기 | 사용자 승인·렌더 버전 관리 |
| 4. Android | Kotlin 앱, 사진 선택, 그룹 제안, 알림, 전송 | 폰 촬영 후 제작 제안·수락 |
| 5. 공식 SNS | YouTube OAuth/업로드/상태·멱등 | 승인 후 업로드·로그 확인 |
| 6. AI 음악 | 상업용 모델 라이선스·성능 실험 | 자산 증빙 남는 생성 음악 삽입 |
| 7. 추가 플랫폼 | Instagram 프로페셔널 API, TikTok 정책 준수 대안 | 각 서비스별 승인 범위만 구현 |
| 8. 전체 비서 | Supervisor, 일정·웰니스·일기, 기억 | 복합 요청 라우팅·권한 분리 |
| 9. 성과 분석 | 지표 수집, 개선 추천 | 채널별 리포트 제공 |

## 결정 지점
- 첫 업로드 API의 실제 계정 권한 및 앱 심사를 검증한 후 P1 범위를 확정.
- PC GPU가 음악 생성에 적합하지 않으면 허가된 무료 라이브러리 음원으로 우선 출시.
- 갤러리 전체 자동 감지는 현재 범위에서 제외. 사용자 선택 업로드만 지원.

## 완료 정의(DoD)
구현 + 단위/통합 테스트 + 권리 검증 + 실패 메시지 + 사용자 안내 + 문서 반영이 모두 완료되어야 기능 종료.

| 6 | 상업용 권리 검증 + 최종 게시 승인 | 버전/해시 검증 및 게시 차단 조건 |
