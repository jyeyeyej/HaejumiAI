## 원칙
**상업적 이용 허용·권리 소유·플랫폼 수익화 가능성은 서로 다른 개념**입니다. 자동 검사 결과는 법률적 보증이 아니며 불명확한 권리는 게시하지 않습니다.

## 에셋 수집 기준
| 자산 | 허용 기준 | 위험 요소 |
|---|---|---|
| 본인 촬영 영상·사진 | 촬영 저작물 + 공개 동의 검토 | 타인 초상권·실내 촬영·배경 음악·상표 |
| 생성 음악 | 모델 정확한 버전과 이용약관, 상업 조건·등록 확인 | 기존 곡 유사성, 수익화 약관 |
| 라이브러리 음원 | 기간·지역·플랫폼·수익화 허가 명시 | 플랫폼 전용 음악의 교차게시 |
| 폰트 | 상업용 영상 및 렌더/배포 허가 | 임베딩/변형 제한 |
| AI 이미지·자막 | 모델 약관·실존 인물·브랜드 권리 확인 | 허위 표현, 제3자 권리 |

## 게이트 결과
- `ALLOW`: 출처·허가 범위·증빙·플랫폼 조건 모두 확인.
- `REVIEW`: 초상권/유사성/불완전한 라이선스 등 사용자의 추가 확인 필요.
- `BLOCK`: 비상업 전용, 범위 초과, 불명확한 권리 또는 정책상 금지.
- `REVIEW`나 `BLOCK`은 자동 공개 게시 불가.

## 생성 음악 선정 정책
- Meta MusicGen 비상업용 가중치처럼 상업 사용 불가 모델은 프로덕션에서 제외.
- Stability AI Community License 대상 모델은 적용 모델명, 연매출 한도, 사전 등록 조건, 약관 버전을 사용 시점에 검증.
- 생성 모델을 선정하기 전에 출력 음원 권리·재배포·SNS 수익화 허용 조건을 법적/정책적으로 검토.

`asset_id`, 출처 URL 또는 촬영자, 생성 도구/모델 버전, 라이선스 식별자·원문 사본, 허용 플랫폼, 상업 사용 가능 여부, 생성 프롬프트/시점, 파일 해시, 검토자/검토일, 게시 URL.

## v0.2 상업용 자동 게시 승인 조건
- 중간 확인(음악/자막)만으로 게시 불가. **최종 게시 승인** + 권리 검사 통과 + API 정책 통과가 모두 필요합니다.
- 음악 생성 모델·가중치·사용 약관의 상업적 허용 범위를 생성 시점마다 증빙하고, 각 플랫폼에서의 재사용 허용 범위를 기록합니다.
- 비슷한 곡 자동 탐지만으로 침해 위험을 완전히 배제할 수 없으며, 불확실할 때 `REVIEW_REQUIRED`로 분류합니다.
