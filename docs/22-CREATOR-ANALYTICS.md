# 크리에이터 성과 분석 설계

> 프로젝트: **해주미(Haejumi)** · AI 비서 이름: **예투**  
> 상태: 설계 초안 v0.2 · 수정일: 2026-10-30 · 대상: 1인 개인용, 향후 다중 사용자 확장  
> 원칙: **존댓말 응답 / 크리에이터 상업적 수익화 / 권리 검증 / 사용자 통제 / 로컬 우선**  
> 표기: **[확정]** 합의된 목표 · **[제안]** 구현 선택 · **[검증 필요]** 정책·환경 확인 전 결정 보류

## 목표
수익화 목표에 맞추어 제작뿐 아니라 어떤 콘텐츠가 성장에 기여하는지 학습하고 다음 제작을 제안합니다.

## 지표 초안
| 지표 | 설명 | 수집 제약 |
|---|---|---|
| 게시 건수 | 기간·채널별 업로드 | 내부 DB 기준 |
| 조회수 | 플랫폼별 노출/조회 | 계정/API 권한 범위 |
| 시청 지속 시간 | 영상 완주·유지 관련 지표 | 플랫폼 제공 여부 다름 |
| 반응 | 좋아요, 댓글, 공유 | 권한/제공 범위 다름 |
| 콘텐츠 특성 | 길이, 스타일, 자막 수, 음악 스타일 | 내부 파이프라인 데이터 |
| 수익 | 플랫폼 수익 정보 | API 접근 가능 여부 검증 필요 |

## 리포트 예시
- “이번 주 업로드 4건 중 음식 클로즈업이 포함된 쇼츠의 평균 조회수가 높았습니다.”
- “시청 지속 시간이 낮았던 영상은 첫 3초 도입부 수정이 필요할 수 있습니다.”

## 주의
- 조회수와 콘텐츠 요소 간 관계는 인과관계로 단정하지 않음.
- 개인 정보와 플랫폼 API 사용 제한 준수.
- 근거 없는 바이럴 보장이나 가짜 참여 증폭 기능 제공 금지.

## 차기 액션
- OAuth/분석 API 접근 가능 항목 조사 후 수집 스키마 확정.
- 사용자에게 추천 이유·근거 데이터·불확실성 함께 제공.
