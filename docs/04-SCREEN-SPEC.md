## S05 상세 수락 기준
- 렌더 중에는 상태 표시(대기/진행/성공/실패) 및 작업 취소를 지원.
- 자막, 음악, 영상 길이, 파일 크기와 저작권 게이트 상태를 표시.
- `수정`은 새 버전을 생성하고 이전 승인 상태 초기화.
- `게시 승인` 버튼은 권리 검증 성공 + 게시 계정 인증 상태일 때만 활성화.

## S06 상세 수락 기준
- 체크한 플랫폼만 게시하며 각 계정·공개 범위를 명시.
- TikTok 제한 등 게시 불가 사유는 자동 우회 없이 설명.
- 게시 요청 이후 타임아웃 발생 시 같은 게시 작업을 중복 생성하지 않음.

## 접근성/반응형
- Android 터치 타깃과 대체 텍스트 고려, 탭 순서·키보드 조작 지원.
- PC는 상세 편집, 모바일은 제안 확인·간단 수정·승인 중심으로 최적화.

## v0.2 모바일 우선 네비게이션 및 승인 화면
- 홈: 콘텐츠 제작/일기 작성/일정 관리/마음·건강 **4개 카드**를 동등하게 표시. Creator는 추천·진행 작업 영역에서 강조.
- 하단: `홈 | 콘텐츠 | 예투 | 내 활동 | 설정`; 내 활동에서 일정·건강·일기 접근. 홈 카드에서도 직접 진입.
- 공통 입력창: 텍스트 작성, 마이크 녹음, STT 결과 편집, 사진·영상 선택, 보내기.
- 음성: 녹음 중/변환 중/변환 오류 표시, 전송 전 인식 텍스트 수정, 재녹음, 취소.
- 콘텐츠 확인: (1) 소스·제작 방향, (2) 자막·음악, (3) 영상 미리보기, (4) 저작권·대상 SNS·공개범위·최종 게시 승인.
- 일기: 사용 기록 확인 → 일기 개요 → 초안 → 최종본 확인/승인 → 정식 저장. 임시 초안과 확정 일기를 구분.
- 공통 컨펌 버튼: `수정 요청 | 보류 | 승인하고 다음`; 마지막은 `최종 저장` 또는 `최종 게시 승인`.
