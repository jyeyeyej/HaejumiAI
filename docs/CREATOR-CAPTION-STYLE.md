## 현재 구현과 제한

사진별 Vision의 관찰 설명은 사실 중심으로 유지합니다. 현재 `per_media_v3` 요청은 별도 자막 후보에만 다정하고 귀여운 일상 브이로그 말투를 요청하며, 음식은 경쾌하게, 풍경은 부드럽게, 게임은 가볍게 재치 있는 표현을 요청합니다. 모델에 고정 예문을 넣지 않았고 이모지·과한 애교체·유행어를 강요하지 않습니다. 사용자 제공 장소 등 명시적 자막 요청은 별도 로컬 근거로 연결하며, 모델의 사진 관찰 결과로 위장하지 않습니다. 새 규격은 과거 v1/v2 캐시를 보존하고 새 말투 분석에 재사용하지 않습니다.

초안 전체에서 정확히 같은 Vision 자막이 반복되면 뒤쪽 후보를 제외하고 사용자 검토 사유를 남깁니다. 유사한 문장 어미와 설명체는 건수만 기록해 화면에서 검토를 요청합니다. 어미만 바꾸거나 사진 사실을 재작성하는 자동 교정은 하지 않으므로 실제 문구의 자연스러움과 사진의 의미 일치는 사용자 확인 및 실제 Vision 검증이 필요합니다. 현재 YouTube 메타데이터 검색만으로 다른 영상의 자막 말투를 분석했다고 주장하지 않습니다.

| 저장 ID | 화면 이름 | 1080×1920 FFmpeg 스타일 | 자동 제안 경로 |
|---|---|---|---|
| `default` | 감성 브이로그 | Noto Sans KR 74px, 흰색, 어두운 외곽선, 0.22초 페이드 | 확인된 여행 장면·카페 분위기의 기존 혼합 편집 제안 |
| `emphasis` | 음식 하이라이트 | 88px, 노란 포인트 컬러, 큰 외곽선, 약 0.18초 확대 팝업 | 확인된 음식 장면의 기존 혼합 편집 제안 |
| `information` | 깔끔한 정보형 | 68px, 상단 반투명 어두운 박스, 흰색, 짧은 페이드 | 기존 정보형 장면 제안 또는 사용자 선택 |

기존 스타일 ID와 장면별 `subtitle_style` 계약을 유지합니다. 장면 편집 화면에서 프리셋을 바꾸고 저장하면 콘텐츠 버전과 관련 승인이 갱신되며, 승인된 자막을 새로 렌더해야 MP4에 반영됩니다. 사진별 AI 분석 설명과 자막 후보는 분리되어 있습니다. 자막 후보는 해당 `media_id`에 묶이고 `needs_review` 상태로 유지됩니다.

서버가 허용된 스타일 ID만 ASS 템플릿으로 변환합니다. 모델이 FFmpeg 필터를 작성하지 않습니다. 기본 자막은 좌우 108px 안쪽, 하단 420px 위에 배치하고 정보형은 상단 320px 아래에 배치합니다. 이 값은 현재 공통 안전 영역의 보수적 초기값이며 음식·얼굴 같은 피사체를 자동 회피하지는 못합니다. 긴 기존 자막은 화면 밖으로 나가지 않도록 크기를 줄이되, 웹에서 짧게 나누라는 안내를 표시합니다.

웹 카드의 미리보기는 스타일과 위치의 **근사치**입니다. 실제 장면 크롭·움직임·폰트 렌더링과 완전히 같지는 않습니다. 최종 확인은 FFmpeg MP4에서 해야 합니다. 글자별 강조 색상, 자유 색상·크기·위치 조절, 스마트 피사체 회피는 아직 구현하지 않았습니다. AI가 첫 2초 후킹 문구나 장면 리듬을 보장하지도 않습니다.

글꼴은 기존 `backend/assets/fonts/NotoSansKR-Regular.otf`를 그대로 사용합니다. 배포 근거와 SIL Open Font License 1.1 전문은 `backend/assets/fonts/README.md`와 `OFL.txt`에 있습니다. 다른 창작자의 영상·음원·자막은 사용하지 않았습니다.

## 합성 실렌더

개인 미디어를 쓰지 않고 흰색·따뜻한 색·하늘색 합성 장면으로 이전 스타일과 새 스타일 MP4를 각각 생성했습니다. 새 MP4는 ffprobe에서 MP4, 1080×1920, 30fps, H.264/AAC, 6초를 통과했습니다. 같은 문구의 추출 프레임에서 세 스타일의 크기와 위치 차이를 직접 확인했고, 음식형 등장 직후와 0.4초 뒤 프레임에서 팝업·페이드 차이를 확인했습니다. 파일은 `data/test-artifacts/caption-style-abwFsV/`에 별도 보관했습니다. 실제 사진·모바일 화면·Chrome의 웹 미리보기와 MP4 일치는 아직 확인하지 않았습니다.
