# LLM 비용 최적화 정책

> 프로젝트: **해주미(Haejumi)** · AI 비서: **예투**  
> 상태: **v0.3 설계 초안** · 2026-10-30  
> 비용 기준: **무료 로컬 처리 우선, LLM은 필요한 경우에만 사용**  
> 표기: **[확정]** 제품 목표 / **[제안]** 구현 방법 / **[검증 필요]** 가격·정책·PC 자원 등 미확정 사항


## 1. 목표 및 범위
- [확정] 1인용 안드로이드 중심 비서 **예투**: Creator, Diary, Schedule, Wellness 4개 전문 에이전트.
- [확정] **사용자 중간 컨펌과 최종 승인**을 유지하면서도 불필요한 모델 호출을 피한다.
- [제안] 로컬 도구·정해진 규칙 → 소형 LLM → 고성능 LLM 순서로 단계적 호출한다.
- [제안] 기본 예산은 **월 5 USD / 일 0.20 USD**를 실험용 초기값으로 설정하며 사용자가 설정에서 수정할 수 있다. 실제 모델 가격·환율·결제 금액의 보증이 아니다.
- [검증 필요] 구체적 모델명·단가·무료 플랜·캐시 할인은 구현 시 공식 가격표 확인 후 결정한다.

## 2. 작업별 비용 경계
| 작업 | 기본 처리 | LLM 사용 조건 |
|---|---|---|
| Android 사진·영상 선택/전송 | Photo Picker + HTTP + 파일 검증 | 없음 |
| 중복 사진 검출·기본 분류 | 파일 해시, 메타데이터, OpenCV | 복잡한 의미 분석 필요 시에만 비전 모델 |
| 장면 편집·변환·렌더링 | FFmpeg + Pillow | 없음 |
| 배경음악 추천 | 상업권 확인된 라이브러리의 태그·점수 매칭 | 애매한 분위기 해석 시 선택 |
| 음성 입력·녹음 전사 | 기기 STT 또는 faster-whisper | 클라우드 STT는 선택형 |
| 음성 자막 싱크 | STT timestamps + FFmpeg | 없음 |
| 제목·영상 설명·해시태그 | 템플릿 + 소형 LLM | 자연스러운 문장/기획 필요 시 |
| 일기 초안 | 소형 LLM | 확인된 당일 일정·감정·건강 요약만 전달 |
| 일정 조회·등록 | Calendar API/규칙 로직 | 모호한 요청 해석 시 |
| SNS 게시 | 공식 플랫폼 API | 없음; 게시 전 승인·라이선스 검증 필수 |
| 감정 관련 대화 | 가벼운 모델부터, 안전 기준 우선 | 맥락 해석이 중요한 경우 모델 사용 |

**주의:** ‘LLM 0원’은 LLM API 요금이 발생하지 않는다는 뜻이며 PC 전기료·저장공간·음원 라이선스·서버 비용까지 0원이라는 뜻은 아니다.

## 3. 라우팅 우선순위
```text
Android 텍스트 또는 음성 → (STT: 로컬 우선)
  → 인증/허용 상태 확인
  → 규칙 라우터(정확히 구별 가능한 명령 및 승인 버튼)
     ├─ 예: 일정 조회/음악 교체/업로드 → 기존 서비스 함수 호출
     └─ 복합·모호한 요청 → 소형 LLM 라우터
           ├─ 가능한 경우 소형 모델로 생성/수정
           └─ 품질 실패·복합 추론 때만 고성능 모델(예산·동의 조건 확인)
  → 단계별 컨펌 → 최종 승인 → 권리/정책 통과 시 저장 또는 게시
```
- [제안] Supervisor가 모든 에이전트 메시지를 매번 대형 모델에 전달하지 않도록 **현재 작업 상태+명령어**로 우선 분기한다.
- [제안] 모델 미응답/예산 초과 시 로컬 모델·규칙형 대안으로 우회하거나 '확인이 필요합니다'를 표시한다. 최종 승인을 우회하지 않는다.

## 4. 수정 요청 시 부분 재실행
- [확정] 사용자가 **음악만 바꿔주세요**라고 하면 기존 사진 분석·문장 생성은 다시 실행하지 않는다. 음악 후보 재선택 → 오디오 리믹스 → 수정본 검토만 진행한다.
- [확정] **자막만 바꿔주세요**는 해당 텍스트 구간만 재작성한 뒤 렌더링한다.
- [확정] 일기에서 **둘째 문단만 수정** 요청 시 해당 문단과 필요한 최소 문맥만 모델에 전달하고 버전을 갱신한다.
- 모든 변경은 콘텐츠/일기 버전을 올리고 이전 버전의 최종 승인을 무효화한다. **콘텐츠 공개 게시와 최종 일기 저장은 최신 버전의 명시적 승인 필수.**
- [제안] 단계별 결과를 `task_id`, `input_hash`, `artifact_version`, `model_version`으로 캐싱한다. 원본/중간 산출물을 임의 재생성하지 않는다.

## 5. 프롬프트·컨텍스트 최적화
1. 장기 기억 전체를 전송하지 않고 목적별로 관련 항목만 조회한다.
2. 일기에는 **당일 일정·당일 감정·당일 건강 데이터·당일 사용자가 말한 사실**과 문체 선호만 포함한다.
3. 멀티미디어는 전체 비디오 대신 **선별된 저해상도 키프레임**만 AI에 전송하도록 제한하고 비용/품질 비교 후 조정한다.
4. 고정 시스템 지침을 앞부분에 두어 지원 모델의 prompt caching 혜택을 평가하되, **캐시 할인이 항상 적용되는 것으로 가정하지 않는다.**
5. 매번 동일한 LLM에 대량의 문서/전체 대화를 다시 전달하는 패턴을 금지한다.
6. 모델 출력 길이와 재시도 횟수에 상한을 설정하고 스키마 검증 실패 시 **무제한 재시도하지 않는다**.

## 6. 예산·호출 제한·관측
### 환경변수 제안 (`.env.example`에 기본값만; 실제 키는 `.env`)
```dotenv
LLM_PROVIDER=hybrid
LOCAL_LLM_ENABLED=true
CLOUD_LLM_ENABLED=true
DAILY_LLM_BUDGET_USD=0.20
MONTHLY_LLM_BUDGET_USD=5.00
MAX_LLM_CALLS_PER_TASK=5
MAX_REVISION_ATTEMPTS=3
MAX_IMAGES_PER_ANALYSIS=5
```
이는 **자체 백엔드에서 직접 구현할 앱 설정**이며 OpenAI API에서 자동 적용되는 공식 환경변수가 아니다.

### 추적 스키마
각 모델 호출 기록: `task_id`, `agent`, `model`, `prompt_version`, `input_tokens`, `output_tokens`, `cached_tokens`(가능한 경우), `estimated_cost_usd`, `latency_ms`, `retry_count`, `result`.
- [제안] 모델 가격표/토큰 사용량 기반 **예상 비용**을 작업 전 계산하고 잔여 예산을 확인한다.
- [제안] DB와 월별 리포트에서 총비용, 작업당 비용, 캐시 적중, 실패 재시도 비용을 추적한다.
- [제안] 예산 소진 시 모델 API 호출을 앱 자체에서 차단하고 사용자가 승인하여 예산을 조정하기 전까지 로컬 처리 또는 보류로 전환한다.
- **[중요]** 앱 내부 한도는 네트워크 요청·동시성·측정 지연에 따라 실제 결제금액과 차이 날 수 있다. 공급자 대시보드의 사용량 알림/프로젝트 제한도 함께 설정한다.

## 7. 모델·가격 비교를 위한 비용 공식
`estimated_cost_usd = (input_tokens * input_rate_per_million + output_tokens * output_rate_per_million) / 1_000_000 + other_usage_cost`
- 이미지·오디오·검색·영상 등은 공급자별 별도 과금 규칙을 확인한다.
- **가격은 하드코딩하지 않고** 설정 파일에 날짜와 단위가 붙은 모델 가격표로 관리한다.
- 비용 계산은 데모 추정치이며 최종 청구액은 공급자 사용량 대시보드로 확인한다.

## 8. 수용 기준/검증 시나리오
- [ ] 단순 일정 조회·음악 교체·파일 업로드가 LLM 호출 0회로 처리된다.
- [ ] 음악 변경 요청 시 사진 분석·자막 LLM을 재호출하지 않는다.
- [ ] 일기 특정 문단 수정 시 필요 문맥만 사용하며 기존 승인 버전은 무효화된다.
- [ ] 예산 초과 시 클라우드 모델 호출이 제한되고 사용자는 이유/대안을 안내받는다.
- [ ] 30일 비용 보고서에서 에이전트·작업별 비용을 확인할 수 있다.
- [ ] 감정·건강 기록은 관련 에이전트에만 최소한으로 제공한다.
- [ ] 비용 최적화가 **권리 검증·최종 승인·보안 검사**를 건너뛰지 않는다.
