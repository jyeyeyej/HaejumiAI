## 전역 공통 규칙
- 존댓말·명료한 피드백, 자동 실패 시 사용자에게 원인·대안 제시.
- 사용자 확인 없이 갤러리 외부 공유 및 공개 게시 금지. 사전 자동 게시 규칙은 별도의 활성화·해지 UI 제공.
- 모든 AI 생성물은 원본/수정본/승인본을 버전으로 기록.
- 필수 권한 거부 시 강요하지 않고 수동 파일 선택 폴백 제공.

## 기능별 의존성
- F-012는 F-007, F-008, F-009 완료 후 진행.
- F-011은 F-010과 제안 정책 문서가 선행되어야 함.
- F-013은 모델별 라이선스 확인과 로컬 성능 측정 이후 활성화.
