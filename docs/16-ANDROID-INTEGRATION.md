## 목표
Kotlin/Jetpack Compose 앱에서 사용자가 직접 선택한 사진·영상을 로컬 PC Creator로 전송하고, 업로드 완료 후 제작을 제안합니다.

## 주요 Android 구성
- Photo Picker: 사용자가 선택한 사진·영상 접근(첫 버전).
- MediaStore 전체 갤러리 검색/주기 감지: **현재 MVP 제외**. 선택 파일의 메타데이터만 필요 범위에서 확인.
- WorkManager [제안]: **이미 사용자가 선택한 업로드의 재시도** 등 작업용. 갤러리 후보 자동 수집 목적 사용 금지.
- NotificationManager: 쇼츠 제작 제안·완료 알림; 알림 권한 요청.
- Room/로컬 DB: 제안 상태·마지막 검사 시각·대기 업로드 작업 저장.
- Tailscale 또는 안전한 로컬 연결: PC FastAPI 접근.

## 선택 업로드 프로젝트 묶음 규칙 [확정]
- 사용자가 직접 선택한 파일을 하나의 프로젝트 후보로 묶습니다. 선택하지 않은 사진은 접근하지 않습니다.
- 선택 자료 내부 촬영시각/EXIF는 필요한 경우에만 로컬 분석하며 위치 권한이 없으면 강요하지 않습니다.
- 서버가 완료한 `manifest_hash + user_id`를 기준으로 중복 제안 차단. **촬영 종료 추측 감지 없음.**

## 권한 UX
1. 첫 실행: 사진 접근 없이도 예투 채팅/수동 업로드 기능 이용 가능.
2. 콘텐츠 기능 시작: Photo Picker부터 제공.
3. 업로드 완료 제안 설정: 사용자가 선택한 파일의 업로드 완료에 대한 알림만 허용/거부. 갤러리 전체 권한 불필요.
4. 권한 취소/일시정지: 업로드 중지 및 업로드된 자료/제안 기록 삭제 옵션 제공.

## 오프라인 동작
- PC 미접속 시 파일 업로드 재시도 및 메타데이터 대기.
- 배터리·데이터 사용량 관리, Wi-Fi 전용 업로드 옵션.
- 강제 종료·재부팅 후에도 중복 제안/업로드 방지.

## 검증 필요
- 실제 휴대폰 Android 버전의 부분 사진 접근 및 백그라운드 제한.
- 장기적인 갤러리 자동 접근이 Play 정책에 부합하는지; 개인 사이드로드라도 OS 권한 제약은 동일.

## v0.2 확정: 선택 업로드 중심 Android UX
- 첫 화면/콘텐츠 탭에서 **Photo Picker**로 사진·영상 파일을 다중 선택하며, 개인 갤러리의 나머지 파일은 조회하지 않습니다.
- 선택한 파일을 Retrofit/OkHttp로 FastAPI에 전송하며, 업로드 진행률·중단·재시도 및 Wi-Fi 전용 설정을 제공합니다.
- 서버의 `data/uploads/{project_id}/` 폴더에 저장 완료 후 예투가 제작 제안을 보냅니다.
- Kotlin/Compose 모바일 화면에서 기획/자막·음악/완성본을 단계별 컨펌합니다.
- 텍스트 및 STT 음성 입력을 동일 대화창에서 지원하며, 오인식 교정 후 전송합니다.
- **전체 갤러리 자동 감시·MediaStore 주기 감지·사진 묶음 자동 발굴은 v0.2 범위에서 제외**하며 향후 별도 동의 기능으로만 고려합니다.
