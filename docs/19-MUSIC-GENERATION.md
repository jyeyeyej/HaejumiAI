# AI 음악 생성 설계

> 프로젝트: **해주미(Haejumi)** · AI 비서 이름: **예투**  
> 상태: 설계 초안 v0.2 · 수정일: 2026-10-30 · 대상: 1인 개인용, 향후 다중 사용자 확장  
> 원칙: **존댓말 응답 / 크리에이터 상업적 수익화 / 권리 검증 / 사용자 통제 / 로컬 우선**  
> 표기: **[확정]** 합의된 목표 · **[제안]** 구현 선택 · **[검증 필요]** 정책·환경 확인 전 결정 보류

## 목적
사진·영상 분위기를 분석하고 **상업적 게시에 사용할 수 있는 배경음악**을 자동 선택하거나 작곡하여 쇼츠에 합성합니다.

> **현행 범위:** MVP는 곡별 상업 이용·플랫폼 허용이 검증된 로컬 음원만 사용합니다. 아래 생성 음악 관련 내용은 [검증 필요/후순위] 설계안이며 출시 조건이 아닙니다.

## 두 가지 모드
- **License-cleared Library:** 사용 조건을 확인한 음악 파일 중 자동 추천. MVP 기본값.
- **Generate Original:** 허용된 모델로 스타일/길이 지정 작곡. 성능·라이선스 검증 뒤 활성화.

## 음악 제작 흐름
`영상 분석 → 분위기(BPM/장르/악기) 결정 → 라이브러리 검색 또는 모델 실행 → 오디오 품질 검사 → 라이선스 기록 → 길이/음량 조절 → FFmpeg 믹스`.

## 음악 프롬프트 예
`Warm, relaxed instrumental for a 30-second cafe travel short, gentle acoustic guitar, soft piano, no vocals, original melody, 95 BPM.`
- 기존 유명 아티스트·곡의 스타일을 그대로 모방하는 프롬프트는 금지.
- 생성된 음악과 기존 곡 간 유사성은 완전 자동 보장 불가; 의심 시 사용자 검토.

## 모델 선정 체크리스트
- [ ] 모델 정식 명칭·버전·가중치 출처
- [ ] 상업 사용과 SNS 수익화 허가
- [ ] 이용자/매출 기준과 사전 등록 필요성
- [ ] 출력물 사용·재배포 권리
- [ ] 해당 시점 약관 사본 보관
- [ ] PC GPU/메모리·생성 시간 측정

## 모델 후보 [검증 필요]
- Stability AI Stable Audio 3.0 Small/Medium: Community License 요건(연매출 한도 및 상업 사용자 등록 등)을 충족하면 후보.
- Meta MusicGen 비상업적 모델 가중치는 상업용 파이프라인에서 제외.
- PC 성능 부족 또는 라이선스 불명확 시 검증된 기존 음악만 사용.

## 음원 처리 기준
- 최종 렌더 전 fade-in/out, loudness normalization, 대화 원음 시 배경음악 ducking 적용.
- 생성 오디오 원본, 프롬프트, 모델 버전, seed(지원 시), 생성 시각, 해시, 권리 증빙 저장.
