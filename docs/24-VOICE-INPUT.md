# 텍스트·음성 입력(STT) 설계

> 해주미 v0.2 · 2026-10-30 · Android 모바일 우선

## 목표
- 홈·예투 채팅·일기 작성·콘텐츠 컨펌 등 모든 주요 요청을 텍스트 또는 음성으로 처리합니다.
- AI는 확인된 텍스트를 공통 입력으로 받아 에이전트에 전달합니다.

## 흐름
1. Android Compose 입력창에서 직접 텍스트를 작성하거나 마이크를 누릅니다.
2. 음성 입력 시 시스템 SpeechRecognizer 또는 선택한 로컬/서버 STT(faster-whisper 등)를 호출합니다.
3. **인식된 문장을 화면에서 편집·재녹음·취소 가능하게 제공**합니다.
4. 사용자가 전송하면 `{mode: "voice_transcript", text, confirmed: true}` 형태로 예투에 전달합니다.
5. Supervisor가 Creator / Diary / Schedule / Wellness로 라우팅합니다.
6. 중간 수정 피드백도 같은 입력 흐름을 사용합니다.

## 음성 컨펌 안전 규칙
- STT가 '게시해 주세요'를 인식해도 게시 UI에서 최종 승인 대상의 제목·플랫폼·공개범위를 명시적으로 확인해야 합니다.
- 일기 저장도 최종본 전체를 표시하고 승인해야 합니다.
- 미인식·잡음·마이크 권한 거절 시 텍스트 폴백을 제공합니다.

## 프라이버시
- 원본 녹음은 기본적으로 변환 후 삭제하고, 장기 저장이 필요하면 별도 동의를 받습니다.
- Android 기본 STT가 네트워크 서비스를 사용할 수 있으므로 오프라인 처리 보장 여부를 구분해 표시합니다.
- 민감한 건강·일기 음성은 로깅과 진단 데이터 수집에서 제외합니다.

## 수용 기준
- 텍스트만으로 모든 주요 흐름 완주 가능.
- 음성 인식 결과를 전송 전 편집할 수 있음.
- 음성으로 '자막 바꿔주세요' 요청 후 새 버전 컨펌 가능.
- 오인식된 최종 승인 문구만으로는 저장/게시가 되지 않음.
