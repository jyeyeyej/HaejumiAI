# PRD — 제품 요구사항 정의서

> 프로젝트: **해주미(Haejumi)** · AI 비서 이름: **예투**  
> 상태: 설계 초안 v0.2 · 수정일: 2026-10-30 · 대상: 1인 개인용, 향후 다중 사용자 확장  
> 원칙: **존댓말 응답 / 크리에이터 상업적 수익화 / 권리 검증 / 사용자 통제 / 로컬 우선**  
> 표기: **[확정]** 합의된 목표 · **[제안]** 구현 선택 · **[검증 필요]** 정책·환경 확인 전 결정 보류

## 제품 개요
- **[확정]** 해주미는 개인화 멀티 에이전트 AI 비서이며, 사용자에게 말을 거는 총괄 비서의 이름은 **예투**입니다.
- **[확정]** 최종 사용자 목표는 사진·영상으로 상업적으로 이용 가능한 콘텐츠를 지속적으로 제작하고 크리에이터로 성장하는 것입니다.
- **[확정]** 우선 사용자는 1명이며 Windows PC와 Android 휴대폰에서 사용합니다. 향후 회원제 확장을 고려하되 MVP에서는 다중 사용자 운영을 구현하지 않습니다.
- **[확정]** 예투는 기본적으로 정중한 존댓말을 사용합니다.

## 해결할 문제
1. 촬영한 맛집·여행 사진이 갤러리에 쌓이지만 영상 편집과 게시가 번거롭습니다.
2. 음악·자막·플랫폼별 게시를 반복적으로 처리해야 합니다.
3. 콘텐츠 저작권 증빙과 게시 상태가 분산됩니다.
4. 일정·일기·감정·건강 상태를 통합하는 개인비서가 필요합니다.

## 제품 비전과 차별성
- 선택 업로드 완료 후 콘텐츠 제작을 **먼저 제안**하는 모바일 기능.
- 사진·영상 → 선별 → 대본/자막 → 음악 → 무료 로컬 렌더링 → 검수 → 게시까지 이어지는 파이프라인.
- 상업용 라이선스의 출처·증빙·정책 버전을 저장하며 불명확한 에셋은 게시 차단.
- Supervisor가 콘텐츠·일정·웰니스·일기 에이전트를 라우팅하고 결과를 통합.

## 범위 및 우선순위
| 구분 | 기능 | 결정 |
|---|---|---|
| MVP-1 | 미디어 수동 선택/업로드, 쇼츠 편집, 자막, 승인 가능한 음악, 미리보기, 로컬 다운로드 | [확정] 최우선 |

## 핵심 사용자 시나리오
- 직접 요청: “어제 카페 사진으로 30초 쇼츠 만들어 주세요.” → 초안 → 음악/자막 → 렌더 → 검토 → 게시.
- 능동형: **사용자가 선택한 파일 업로드 완료** → 예투 제작 제안 → 사용자 수락 → 편집. 전체 갤러리 자동 감지는 제외.
- 다중 작업: “보고서 마무리하고 여행 사진도 정리해 주세요.” → Supervisor가 순차/병렬 계획.

## 품질 기준 (초안, 실측 후 조정)
- 업로드된 사진 5~10장과 짧은 클립으로 9:16 MP4를 출력할 수 있어야 합니다.
- 게시 및 민감한 외부 작업에는 사용자 승인 또는 명시적으로 허용한 규칙이 있어야 합니다.
- 라이선스 정보가 미확인인 음악·폰트·이미지는 자동 게시할 수 없어야 합니다.
- 실패한 작업은 중복 게시 없이 재개/재시도 가능해야 합니다.

## 비목표
- AI가 실존 인물이나 저작권 있는 영상 장면을 새로 생성하는 기능은 초기 범위에서 제외.
- 의료 진단/치료, 무단 갤러리 전체 열람, 플랫폼 정책을 회피한 업로드는 제공하지 않음.

## 열린 결정
- [ ] 현재 PC의 GPU/메모리와 Android OS 버전 확인
- [ ] 첫 배포 채널과 수익화 정책별 사업용 계정 확인
- [ ] AI 모델(API/로컬)별 월 비용 한도 확정

## v0.2 확정 제품 방향
- **Mobile First:** Android 앱이 핵심 사용 화면입니다. Windows PC는 FastAPI·에이전트·FFmpeg·저장소를 운영하는 로컬 서버입니다.
- **명시적 미디어 선택:** 전체 갤러리를 자동 스캔하지 않습니다. 사용자가 Android Photo Picker로 원하는 사진·영상만 선택하면 서버에 프로젝트별 폴더로 저장합니다.
- **능동형 제안의 트리거:** 선택 파일의 업로드가 완료되면 예투가 쇼츠 제작을 먼저 제안합니다. 추후 전체 갤러리 감지는 별도 opt-in 없이는 구현하지 않습니다.
- **4개 전문 에이전트:** Creator / Schedule / Wellness / Diary. 업무 문서 작성 에이전트는 현재 제품 범위에서 제외합니다.
- **입력:** 텍스트와 음성(STT→인식문 확인·수정)을 공통으로 지원하며, 예투는 존댓말을 사용합니다.
- **공통 승인:** 계획→중간 컨펌→초안/미리보기→최종 컨펌. 정식 일기 저장과 SNS 게시는 최종 승인 후 실행합니다. 임시 초안은 별도 보관합니다.
- **상업화:** 음악·폰트·사진·영상·플랫폼별 사용 권리 증빙과 차단 규칙을 유지합니다.
- **MVP 성공 시나리오:** Android에서 사진 8장·영상 2개 선택 → PC 업로드 → 예투 제작 제안 → 스타일/자막/음악 승인 → FFmpeg 영상 → 미리보기 승인 → 권리 확인 → 허용된 SNS 게시.
