## 보호 대상
- Android 갤러리(위치정보/얼굴 포함 가능), OAuth 토큰, 개인 일정, 감정·건강 기록, 업무 문서, AI 기억, 생성물.

## 권한 최소화
- 안드로이드는 선택 사진 접근을 기본으로 하며, 전체 갤러리 접근은 실제 기능 필요성과 OS 정책 충족을 검증한 뒤 선택적으로 제공.
- 갤러리 감지·분석 제안은 별도 opt-in 및 언제든 해제.
- Wellness 자료는 기본적으로 Creator Agent와 공유하지 않음.
- 게시 계정 연결은 필요한 OAuth scope만 요청하고 취소/연결 해제 제공.

## 인증·저장
- 개인용 로컬 서버도 세션 인증/잠금 필요, 로컬 네트워크에 인증 없는 관리 API 공개 금지.
- PC·Android 연결은 Tailscale 사설 네트워크 + 필요 시 HTTPS 적용.
- API 키·OAuth 토큰은 `.env` 및 비밀 저장 수단 사용, Git에 절대 커밋하지 않음.
- 중요 비밀은 로그에 마스킹, 파일 경로는 서비스 저장소 내로 제한(path traversal 방지).
- 사진/영상·백업은 접근 제한된 디렉터리에 저장, 민감 기록은 암호화 고려.

## 삭제 및 보존
- 원본·렌더·캐시·제안·기억에 각각 보존 기간과 삭제 경로 정의.
- 삭제 요청 시 작업 큐와 검색 인덱스에서도 제거, 백업 잔존 기간 안내.
- 수익화 관련 라이선스 증빙은 콘텐츠 유지 기간 중 보존 필요성 고려.

## v0.2 개인정보 최소 수집 및 승인
- 첫 버전에서 Android 갤러리 전체 읽기·상시 자동 감지를 요청하지 않습니다. **Photo Picker로 명시적으로 선택한 파일만** 서버로 전송합니다.
- STT 음성은 변환 후 사용자 검토를 거치며, 원본 음성 미보관을 기본값으로 설계합니다. 제3자 STT API 사용 시 사전 고지·선택권 제공.
- 일기·감정·건강 정보는 높은 민감도로 취급하고 콘텐츠 에이전트와의 무단 공유를 차단합니다.
- 최종 승인 전 정식 일기 저장·외부 SNS 전송 금지. 임시 초안 보관/삭제 정책 명시.


## v0.3.1 개인정보 외부 전송 통제 — 추가 개발 필수 기준
- **로컬 처리 기본값**: 외부 LLM·STT·비전·분석 업체로 개인 기록/미디어를 자동 전송하지 않습니다. 사용자 요청이나 AI 프롬프트만으로 외부 전송 권한이 생기지 않습니다.
- **전송 게이트**: Backend가 목적, 수신 업체, 전송 항목, 민감도, 최소화 가능성, 동의 범위/만료를 검증한 뒤 허용 목록에 있는 서비스만 호출합니다. 검증 실패·동의 철회·오프라인은 차단합니다.
- **사적 데이터 통제**: 외부 업체 API 전송은 인터넷 공개와 다르지만 제3자 처리에 해당할 수 있으므로 동의 UI에 대상·내용·목적을 구분합니다. 특정 외부 업체의 보존/학습 정책을 임의 보장하지 않습니다.
- **보호 대상**: 일기·웰니스·일정·기억·연락처·음성·사진(EXIF/GPS/얼굴)·토큰; 에이전트별 최소 접근, 로컬 저장 암호화/OS 접근제어, 로그·오류·텔레메트리 원문 차단.
- **파일 취급**: `.env`, OAuth 토큰, 백업, `data/`는 Git에서 제외. 선택하지 않은 사진 접근 불가. 프롬프트 인젝션을 도구 명령으로 실행하지 않습니다.
- **게시 승인 별도**: 개인정보 전송 동의는 SNS 게시 승인으로 대체할 수 없습니다. 공개 게시에는 **게시물별** 최종 버전·해시·플랫폼·계정·공개범위 승인과 권리 게이트가 모두 필요합니다.
- **보존·삭제**: 전송 동의 철회, 임시 파일·음성·캐시·기억·백업의 보존기간/삭제 정책을 구현 전 정의하고 사용자에게 명시합니다.
- **검증**: 외부 HTTP mock으로 동의 없는 호출 0건, 민감 기록 Creator 조회 거부, 로그/오류 정보 누출 0건, 구버전 승인/게시 차단, 토큰 비노출을 자동 테스트합니다.
