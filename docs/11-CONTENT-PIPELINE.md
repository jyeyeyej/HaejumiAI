## v0.4 Creator 공통 출력 규격 — [확정]
- 화면 9:16, 1080×1920, MP4, H.264 영상, AAC 오디오, 30fps.
- 길이 3초 이상 60초 미만. 기본 30초이며 사용자가 3~59초에서 설정합니다.
- YouTube Shorts·TikTok·Instagram Reels에 공통으로 내보낼 파일을 목표로 합니다. 플랫폼별 게시 API·계정·권리 승인은 별도이며 이 출력 규격만으로 게시를 승인하지 않습니다.
- 로컬 FFmpeg로 만들고 완료 후 ffprobe가 container, 해상도, 지속시간, 영상/오디오 codec, frame rate를 확인합니다. 하나라도 불일치하거나 ffprobe를 실행할 수 없으면 결과를 `ready`로 취급하지 않습니다.
- `fit_pad`: 원본 화면 전체를 축소해 넣고 남는 영역에 여백을 둡니다. `fill_crop`: 화면을 채우도록 크롭하며, 사용자가 지정한 초점 좌표를 적용할 수 있습니다. 기본은 중요한 부분을 자르지 않는 `fit_pad`입니다.
- 자막 등 UI에 가릴 수 있는 요소는 공통 안전 영역 안에 둡니다(1080×1920 기준 좌우 10%, 상단 15%, 하단 20%를 예약). 피사체 자동 검출/추적은 보장하지 않으며, 크롭 모드에서는 초점을 미리보기에서 확인·수정해야 합니다. 플랫폼 UI와 실기기 검증 전까지 안전 영역은 보수적 제안값입니다.
- 기술 출력 규격 확정은 콘텐츠·음악·초상권 검증이나 별도의 사용자 최종 게시 승인을 대체하지 않습니다.

## 목표
본인 촬영한 사진·동영상으로 3~59초 세로형 콘텐츠를 만들고 **권리 검사 + 승인 + 플랫폼별 게시**까지 연결합니다. 기본 길이는 30초이며 첫 목표는 1080×1920 9:16 MP4입니다.

## 단계 및 산출물
| 단계 | 입력 | 처리 | 출력 | 검증 |
|---|---|---|---|---|
| 1. 감지·선택 | Android 사진/영상 | 허용 범위만 수집 | media refs | 권한·형식 |
| 2. 그룹화 | EXIF/촬영시각/선택 장소 | 동일 방문 후보 분류 | group | 오탐 수정 가능 |
| 3. 제안 | group + 사용자 설정 | 먼저 제작 제안 | proposal | 중복·방해금지 |
| 4. 분석 | 선택 미디어 | 장면 점수, 중복 제거 | media plan | 민감 장면·초상권 경고 |
| 5. 편집 계획 | 목표 길이·스타일 | 컷 구성·비율 조정 | edit JSON | 길이 범위 |
| 6. 자막 | STT 또는 소개 문안 | 타임코드·교정 | SRT/ASS/JSON | 오탈자·허위 주장 |
| 7. 음악 | 허가된 라이브러리 또는 생성 모델 | BPM/스타일·길이 맞춤 | audio asset | 상업용 라이선스 |
| 8. 렌더 | edit + assets | FFmpeg 합성·트랜지션 | draft MP4 | 9:16, 코덱·음량 |
| 9. 권리 검사 | 모든 에셋 + 라이선스 증빙 | 플랫폼별 허가 확인 | pass/review/block | 불명확하면 차단 |
| 10. 검수 | 영상/자막/음악 | 미리보기·수정 | approved version | 파일 해시 승인 |
| 11. 게시 | 승인본 + OAuth | 공식 API 호출 | URL/결과 | 멱등성·사후 상태 |

## 편집 구현
- FFmpeg: scale/pad/crop, concat, xfade, drawtext/subtitles, loudnorm, audio mix, H.264/AAC.
- Pillow: 정적 타이틀 카드·썸네일·이미지 전처리.
- faster-whisper: 음성 포함 클립 자동 전사; 말이 없는 경우 경험 기반 자막 문안 생성.
- 영상 프리뷰는 저해상도 프록시를 먼저 생성하여 빠르게 제공.

## 사용자 승인
- 초안 재생/자막·음악 수정 → 새 버전 렌더 → rights check → 승인 → 게시.
- 원본·편집 JSON·출력물·라이선스 스냅샷을 프로젝트 ID로 묶어 저장.

## 예외 정책
- PC 오프라인: `WAITING_FOR_WORKER`로 보류.
- 권리 불명확: `BLOCKED_RIGHTS`, 대체 음원 추천.
- 플랫폼 게시 불가: 로컬 MP4 다운로드 또는 공식 앱 공유.
- 영상에 제3자 얼굴/상표/배경음악이 포함되면 사용자 검토 플래그로 표시.

## v0.2 확정 콘텐츠 입력·컨펌 파이프라인
1. **Android Photo Picker 선택** (전체 갤러리 자동 탐색 금지) → 선택 자료만 서버 전송 → `data/uploads/{project_id}` 저장.
2. 업로드 완료 감지 → 예투가 **제작 제안** → 수락/보류/취소.
3. **중간 컨펌 1:** 사용할 미디어, 순서, 목표 길이, 분위기·콘셉트 승인/수정.
4. **중간 컨펌 2:** 자막 초안, 음성 인식 결과(원본 영상에 말소리가 있는 경우), 음악 후보 또는 AI 작곡 결과 검토/수정.
5. FFmpeg 렌더 → 모바일 미리보기 → 자막·음악·컷 수정 요청 시 새 버전 렌더.
6. 플랫폼별 라이선스·초상권·허위정보 위험·기술 품질 검증.
7. **최종 컨펌:** 완성 영상 해시, 제목, 설명, 플랫폼, 공개 범위 확인 → 승인된 버전만 업로드.
8. SNS API 제약으로 불가능한 플랫폼은 사용자에게 명시하고 수동 공유/내보내기 경로 제공.
- 중간 승인 없는 자동 게시 금지. 최초 버전은 사용자 최종 승인 필수. 작업 중단 후 이어하기 지원.

## v0.3 — 미디어 제작 시 LLM 절약
- 해시·메타데이터·OpenCV로 처리 가능한 선별/분류는 로컬에서 실행한다. 영상 전체 대신 필요한 키프레임만 비전 분석에 사용한다.
- 저장된 라이선스 허용 음악의 태그 매칭은 규칙 기반으로 처리한다. 사용자가 음악만 변경하면 오디오 합성 단계만 재실행한다.
- 자막 변경 시 타임라인/기존 분석을 재사용한다. 최종 승인 및 라이선스 검사 과정은 절대 생략하지 않는다.
