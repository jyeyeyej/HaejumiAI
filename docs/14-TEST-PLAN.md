## 테스트 레벨
- Unit: 라우터, 그룹화, 라이선스 게이트, 자막 타이밍, 파일 검사.
- Contract: Pydantic/OpenAPI, Android/React–FastAPI 필드 합치기.
- Integration: FFmpeg 실행, DB 롤백, 작업 큐, OAuth 모의 서버.
- E2E: Android 선택 → 렌더 → 승인 → 테스트 채널 게시.
- AI eval: 의도 라우팅, 잘못된 사실 생성, 부적합 음악 선택, 대화 존댓말.
- Security: 권한 거부, 토큰 유출, SSRF·경로 탐색, 파일 업로드 공격.
